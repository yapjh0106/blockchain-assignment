# LogiChain

🌍 **Live Demo:** [https://blockchain-assignment-l3x7.onrender.com/](https://blockchain-assignment-l3x7.onrender.com/)

A blockchain-based decentralized application (DApp) that facilitates trustless, milestone-based payments between Shippers and Carriers using Ethereum smart contracts. This platform utilizes a smart contract architecture containing a User Registry, a Carrier Reputation Token (CRP), and a LogiChain system to manage end-to-end logistics operations transparently.

## Features
- **Role-based Dashboards:** Dedicated interactive interfaces for Shippers, Carriers, and Administrators.
- **Milestone-Based Payments:** Split payments natively across two verifiable milestones (Pickup and Final Delivery).
- **Dispute & Refund System:** Shippers can securely cancel unfunded or expired agreements, while carriers can reject shipments under specific conditions. 
- **Carrier Reputation System:** ERC20-based Carrier Reputation Token (CRP) incentivizes Carriers for successfully verified milestones and completed agreements.
- **Real-time Cryptocurrency Conversion:** Live API integration to visualize real-time Ethereum values directly in USD natively in the dashboard.
- **File Attachments:** Integrated attachment capabilities to verify shipment evidence transparently.

## Prerequisites
Before you begin, ensure you have the following installed on your machine:
- [Node.js](https://nodejs.org/en/download/) (v14 or newer)
- [Truffle Suite](https://trufflesuite.com/docs/truffle/getting-started/installation/) (`npm install -g truffle`)
- [Ganache](https://trufflesuite.com/ganache/) (for local blockchain testing)
- [MetaMask](https://metamask.io/) browser extension

## Installation

1. **Navigate to the Project Directory**
   Ensure you are in the root directory of the project:
   ```bash
   cd LogisticsEscrowDapp
   ```

2. **Install Dependencies**
   Install the necessary Node.js dependencies for the project:
   ```bash
   npm install
   ```

3. **Configure Environment Variables**
   Create a `.env` file in the root directory and add the following keys. These are required for smart contract deployment to Sepolia and backend file storage (Supabase):
   ```env
   # Supabase (for backend document storage)
   SUPABASE_URL="https://your-supabase-url.supabase.co"
   SUPABASE_SERVICE_KEY="your-supabase-service-role-key"

   # Ethereum Network Deployment (for truffle migrate to Sepolia)
   MNEMONIC="your twelve word mnemonic phrase goes here"
   INFURA_API_KEY="your-infura-api-key"
   ```

## Smart Contract Deployment

> [!NOTE]
> If you are using the cloned GitHub repository, you can skip this step and proceed directly to [Running the Application](#running-the-application).

This project contains three core contracts: `UserRegistry.sol`, `CarrierReputationToken.sol`, and `LogisticsEscrow.sol`.

### Local Deployment (Ganache)
1. Open and start Ganache. Ensure it is running on `HTTP://127.0.0.1:7545` (or update `truffle-config.js` to match your local RPC port).
2. Deploy the contracts to your local network:
   ```bash
   truffle migrate --network development --reset
   ```

### Testnet Deployment (Sepolia)
1. Ensure your `.env` configuration file contains a valid Infura API Key and your deployer account mnemonic.
2. Deploy to Sepolia:
   ```bash
   truffle migrate --network sepolia
   ```

## Running the Application

The application is served by an Express backend (`server.js`) that handles both static frontend files and Supabase file uploads via an API.

1. **Start the Server:**
   Run the Node.js server from the project root:
   ```bash
   node server.js
   ```

2. **Access the DApp:**
   Open your browser and navigate to:
   ```text
   http://localhost:3000
   ```

## MetaMask Setup

To interact with the application, you must configure your MetaMask wallet:

1. **Connect to the Network:**
   - If using **Ganache**: Add a custom network in MetaMask using RPC URL `http://127.0.0.1:7545` and Chain ID `1337` (or `5777`).
   - If using **Sepolia**: Switch MetaMask to the Sepolia test network.

2. **Import Accounts (Local Development Only):**
   Copy the private keys generated by Ganache and import them into MetaMask so you have test ETH to interact with the smart contracts.

3. **Interact:**
   Click the "Connect Wallet" button on the DApp landing page. Approve the connection prompt in MetaMask to access your role-based dashboard.
